Tarifas de las cabañas

Precio por noche: un precio base para las personas incluidas, más un cargo por cada persona extra. Los cambios aplican a las nuevas solicitudes.

Temporadas y promociones

Una temporada cambia el precio base de un rango de fechas (por ejemplo, temporada alta). Una promoción descuenta un porcentaje o un monto por noche en ese rango. Si una noche tiene ambas, primero se aplica la temporada y después la promoción. Los cambios aplican a las reservas que se creen o se editen después.
